# Out of Scope

Record deliberately rejected ideas, features, and refactors here (one short markdown file per decision).

Agents check this directory before proposing enhancements so the team does not re-litigate closed decisions.

## Format

```markdown
# <Short title of rejected idea>

**Decision:** Out of scope (do not propose or implement).
**Why:** 1–3 sentences explaining the constraint or trade-off.
**Revisit only if:** Concrete condition that would change this decision.
```
